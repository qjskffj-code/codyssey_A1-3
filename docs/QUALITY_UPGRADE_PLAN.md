# Bound Mission 완성도 향상 계획

## 판단

현재 버전은 미션 요구를 설명하고 시연하기에는 충분하지만, Away와 나란히 보면 공간감·전환·고유한 장면이 부족해 일반적인 대시보드처럼 보일 수 있다. 제출 전에는 기능을 더 늘리기보다 핵심 흐름의 시각적 완성도를 높인다.

기존 Bound와 같은 디자인 원칙을 쓰는 것은 문제되지 않는다. 다만 Things를 바로 떠올리게 하는 정확한 메뉴 순서, 아이콘 형태, 색 조합, 문구, 화면 배치를 복제하지 않는다.

## 유지할 것

- Bound의 절제된 여백과 명확한 정보 위계
- 입력 직후 상태가 자연스럽게 변하는 짧은 모션
- 같은 기능에 같은 모양과 반응을 적용하는 일관성
- Away에서 검증한 화면 간 상태 연결과 이야기 흐름

## 제출용 고유 경험

핵심 흐름을 `Thoughts → AI Frame → Project → Today`로 고정한다.

1. **Thoughts**: 막연한 생각이 떠 있는 시작 장면
2. **AI Frame**: 생각이 AI를 통해 끝점·장애물·경계·첫 행동으로 바뀌는 장면
3. **Project**: 정리된 프레임을 한눈에 비교하는 집중 장면
4. **Today**: 첫 행동 하나를 실행하는 장면

## 우선순위

### 1. 변환 순간 강화

- AI 실행 중에는 입력 카드와 결과 카드 사이에 짧은 연결 모션 사용
- 결과 항목을 한꺼번에 띄우지 않고 Goal → Hurdle → Boundary → Action 순으로 등장
- 동작 줄이기 설정에서는 즉시 표시

### 2. 프로젝트 상세 화면 강화

- 일반 카드 나열 대신 끝점과 장애물의 관계가 드러나는 고유한 배치 사용
- 핵심 허들은 하나, 바운더리는 최대 세 가지라는 제한을 시각적으로 표현
- First Action을 Today에 보내는 연결을 명확히 제공

### 3. 시각 언어 정리

- Bound Mission 전용 아이콘과 디자인 토큰 사용
- 카드, 여백, 그림자, 모서리, 상호작용 상태를 일관되게 정리
- Things를 식별하게 하는 화면 구성과 에셋은 사용하지 않음

### 4. 제출 화면 준비

- 데스크톱 핵심 흐름 4장과 모바일 화면 2장 캡처
- 입력 전, AI 변환 중, 결과, 행동 완료 상태 포함
- 실제 데이터와 API 키가 노출되지 않았는지 최종 확인

## 완료 기준

- 첫 방문자가 30초 안에 제품의 고유한 흐름을 설명할 수 있다.
- Away와 나란히 보아도 화면의 깊이와 전환 완성도가 낮아 보이지 않는다.
- Things의 이름이나 화면을 보여주지 않아도 Bound Mission의 가치를 이해할 수 있다.

## 적용 기록

- Capture → Frame → Shape → Act를 상단 여정으로 연결
- AI 처리 중 프레이밍 경로를 보여주는 전환 상태 추가
- AI 결과를 Project와 Today로 보내는 실제 연결 구현
- Goal, Desired Response, Hurdle, Boundary를 독자적인 프로젝트 블루프린트로 재배치
- 호출 한도 중에도 전체 흐름을 확인할 수 있는 명시적인 샘플 프레임 추가
- About 화면에 Away에서 출발한 문제와 제품 설계 원칙을 전면 배치
